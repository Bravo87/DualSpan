# Contributing to DualSpan

Thanks for helping build a free, open-source monitor-window spanner. Open a GitHub issue with your operating system, desktop environment, display server, monitor layout, reproducible steps, expected and actual results. Pull requests are welcome. Please run `python -m unittest discover -s tests -v` and `python -m compileall -q dualspan dualspan.py` before submitting. Keep MIT licensing and do not claim universal Wayland or fullscreen-game support.
